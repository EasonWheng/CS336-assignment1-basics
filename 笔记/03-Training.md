## 学习率

`experiments/lr_tuning.py` 抄的是手册 4.2.1 的式 (20)：

$$\theta_{t+1} = \theta_t - \frac{\alpha}{\sqrt{t+1}} \nabla L(\theta_t)$$

玩具问题是 `(weights**2).mean()`，`weights` 为 10×10，初值取 `5 * torch.randn`。四组学习率 1、1e1、1e2、1e3 各跑 10 步，每组用同一个种子，只有 `lr` 不同。

初始损失 24.17，种子 42。`lr=1` 和 `lr=1e1` 下损失下降很慢，十步后分别还剩 20.00 和 3.25；`lr=1e2` 四步内降到 1.5e-16，是最快的一组；`lr=1e3` 时损失每一步放大 361 倍，第十步到 2.2e18，训练发散。

乘上多少可以直接算。`L = mean(w²)` 摊在 100 个元素上，`∇L = 2w/100 = w/50`，式 (20) 变成

$$w \leftarrow w - \frac{\alpha}{50\sqrt{t+1}} w = w\left(1 - \frac{\alpha}{50\sqrt{t+1}}\right)$$

第一步 `t=0` 的系数是 `1 - α/50`：α=1 得 0.98，α=10 得 0.8，α=100 得 −1，α=1000 得 −19。损失正比于 `w²`，第一步之后损失与初值之比就是系数平方，四组实测依次是 0.96、0.64、1.00、361，对应 0.98²、0.8²、(−1)²、(−19)²。α=100 的第二步系数是 −0.414，step2/step1 是 0.1716 = 0.414²；第四步系数正好是 0，`w` 归零，损失掉到 1.5e-16。

## 优化器的演化

从 SGD 到 AdamW，每一代补的是前一代留下的一个缺口。

**小批量**。`g_t = (1/B) Σ_{i∈B_t} g_i`，是全量梯度的无偏估计，方差比单样本降 `B` 倍。现代训练里说的「SGD」都是这一种。

**动量**。`v_t = βv_{t-1} + (1-β)g_t`，`θ_t = θ_{t-1} - ηv_t`，β 取 0.9。峡谷地形里垂直方向的梯度相邻两步反号，进 `v` 后相互抵消；沿谷底方向同号，`v` 一路累积。PyTorch 的 `SGD(momentum=0.9)` 写成 `v = βv + g`，稳态下 `v` 是 `(1-β)` 形式的 `1/(1-β)` 倍，等效学习率放大 10 倍，两种写法折算学习率后等价。NAG 把梯度取在 `θ - ηβv_{t-1}` 的预判位置上，动量冲过头时那里的梯度已经反号，能提前刹车。

**Adagrad**。`s_t = s_{t-1} + g_t²`，更新是 `θ -= ηg_t/(√s_t + ε)`。梯度常年大的参数分母大、步子小，稀有特征对应的参数步子大。`s` 只增不减，练久了所有参数的步长都趋近 0。

**RMSProp**。`s_t = ρs_{t-1} + (1-ρ)g_t²`，ρ 取 0.9 或 0.99。近期梯度小，`s` 跟着小，步长能回升。

**Adam**。`m` 用 β₁ 平滑、`v` 用 β₂ 平滑，两个都从 0 起步，前几步偏小，要除以 `1-β^t` 修正。分母是 `√v̂ + ε`，ε 取 1e-8。LLaMA 和 GPT-3 用 (0.9, 0.95)。

**AdamW**。L2 正则把 `λθ` 加进梯度，Adam 随后把整个梯度除以 `√v̂`，衰减项跟着被缩放：梯度方差大的参数衰减得轻，方差小的几乎按 `ηλ` 全额衰减。`λ` 从此不再等于「每步乘 `(1-ηλ)`」。AdamW 把 `λθ` 从梯度里拿出来，单独做 `θ ← θ - ηλθ`，不参与 `m`、`v`。

### 手册规定的写法

Algorithm 1 的 `t` 从 1 开始，衰减在矩估计更新之前做。偏差修正折进了步长：

$$\alpha_t = \alpha\frac{\sqrt{1-\beta_2^t}}{1-\beta_1^t}, \qquad \theta \leftarrow \theta - \alpha_t \frac{m}{\sqrt{v} + \varepsilon}$$

`m`、`v` 用的是未修正的值，ε 也没被修正。测试注释说不同的衰减写法「原则上等价，浮点上不同」，所以测试先比 `torch.optim.AdamW`，差在 1e-4 以内直接过，对不上再比参考快照。

构造签名按测试传：`opt_class(model.parameters(), lr=1e-3, weight_decay=0.01, betas=(0.9, 0.999), eps=1e-8)`，跑 1000 步 3→2 的线性回归，比最后的 `weight`。

## AdamW 实现

`cs336_basics/optimizer.py:7`。构造参数 `lr=1e-3`、`betas=(0.9, 0.95)`、`eps=1e-8`、`weight_decay=0.3`，四个超参各自检查范围后拼成 `defaults` 交给 `super().__init__`。betas 取 (0.9, 0.95) 是 LLaMA 的口径。

三份状态在 `step` 里懒建，`.get` 的默认值充当零初值：

```python
t = state.get("t", 1)
m = state.get("m", 0)
v = state.get("v", 0)
```

`.get` 只读不写，真正存下来靠后面的 `state["m"] = ...`、`state["v"] = ...`、`state["t"] = t + 1`。`t` 记的是当前步数，第一次进来就是 1，α_t 要用当前值，末尾再加一。α_t 依赖每个参数各自的 `t`，放在参数循环里算。

第一版把新的 m、v 写进 state 之后，参数更新那行读的还是进来时的局部变量：

```python
state["m"] = betas[0] * m + (1 - betas[0]) * grad
state["t"] = t + 1
p.data -= alpha_t * m / (v ** 0.5 + eps)     # 旧的 m、v
```

第一步 `m`、`v` 都是 0，更新量 `alpha_t * 0 / (0 + eps)` 是 0，参数原地不动；后面每一步都用前一步的矩，整体滞后一拍。1000 步跑完 6 个权重里有 2 个对不上，最大绝对差 2.96e-4，超过 1e-4 的容差。写完 state 之后重新取值再更新，测试通过。
